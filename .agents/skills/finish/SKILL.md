---
name: finish
description: Verify the real changed surface, simplify the diff and close an Agent SOP session.
---

Exercise the changed application or CLI on its actual surface, including a
known failure case. For prose-only changes review the documents directly.
Inspect the diff for unnecessary complexity, make justified simplifications,
and rerun relevant checks. Use update-sop to close the session. If requested,
prepare the PR against the correct default branch with a concise change and
validation description. Do not infer permission to merge, publish or release
from a request only to verify or prepare changes. Report what was verified
and any unresolved blocker.
